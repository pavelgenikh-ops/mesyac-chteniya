# Месяц чтения

Приложение на телефон по рилсу @islam_khanin «6 тем, которые за месяц сделают тебя неприлично образованным» (01.11.2026).

## Что внутри

- **30 уроков** — 6 тем по 5 дней: теория игр (лекции Бена Поляка, Йель), когнитивные искажения (Канеман),
  история философии (Уорбертон), почему одни страны богатеют (Аджемоглу и Робинсон + Our World in Data),
  история искусства (Гомбрих + Google Arts & Culture), статистика (Хафф).
  Урок = конспект на 7–10 минут (своими словами, примеры со стройки) + что посмотреть или прочитать в оригинале
  + главное + задание на день + 3 вопроса с пояснениями.
- **Книги** — тексты книг под авторским правом, в приложение не вшиты. Купленный файл FB2, FB2.ZIP, EPUB или TXT
  загружается во вкладке «Книги» и читается прямо в приложении: оглавление, закладка, размер шрифта, ночная тема.
  Файл хранится только в телефоне.
- Прогресс (пройденные дни, ответы, место в книге) — тоже только в телефоне (`localStorage`, `IndexedDB`).

## Как открыть

- На компьютере — `Открыть на компьютере.bat` (или двойной клик по `index.html`), сервер не нужен.
- Для проверки с сервером — превью `mesyac` (порт 8143, `дети\.claude\launch.json`).
- **На телефоне** — https://pavelgenikh-ops.github.io/mesyac-chteniya/ (QR — `QR-код для телефона.svg`).
  Открыть ссылку и добавить на главный экран: iPhone — Safari → «Поделиться» → «На экран Домой»;
  Android — Chrome → ⋮ → «Добавить на гл. экран». После первого открытия работает без интернета.
  Репозиторий `pavelgenikh-ops/mesyac-chteniya` (публичный: уроки видны всем, у кого есть ссылка;
  книги и прогресс остаются только в телефоне).

## Как выложить доработку

1. `_служебное\build.js` — обязательно (поднимает версию, иначе телефон возьмёт старое из кэша).
2. `git add -A` → `git commit -m "…"` → `git push`. Через 1–2 минуты телефон покажет плашку «Появилась новая версия».

## Как править уроки

1. Править `content\NN-тема.json` (формат — `_служебное\формат-урока.md`).
2. Собрать: `_служебное\build.js` любым node (например `дети\02 - Школа Вики\_dev\node.exe _служебное\build.js`) —
   проверяет уроки, пишет `js\lessons.js` и поднимает версию `?v=` (без этого телефон возьмёт старое из кэша).
3. Карта устройства — `ARCHITECTURE.md` и `Карта.html`, обновлять вместе с программой.
